# Múa Lân Booking Platform

## Overview

The Múa Lân Booking Platform is a full-stack web application that allows customers to book lion dance performances for events such as:

- Lunar New Year
- Grand openings
- Weddings
- Cultural celebrations

The platform provides a streamlined booking system while allowing administrators to manage incoming performance requests.
